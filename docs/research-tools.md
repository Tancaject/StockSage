# 研究工具与 Skill

从工作台「工具 / Skill」进入。页面读取实际注册目录，选择工具后填写参数，或选择 Skill 一次执行已声明的步骤；结果含原始输入、来源、计算公式、状态及缺口，可下载 JSON。输入示例仅说明格式，示例中的价格、持仓和预期不是市场数据，执行前应替换。

## 能力范围

| 范围 | 实现与输入边界 |
|---|---|
| 官方原文与披露比较 | SEC、巨潮、沪深交易所、港交所的明确原文 URL；HTML/PDF、章节、表格、块ID、分页、同章节增删。扫描PDF不做OCR。见[正文契约](architecture/disclosure-reading.md)。 |
| 历史研究 | 本人报告、证据快照、报告差异、旧论点与新证据对照、当前自选列表的研究变化；报告 ID 从历史列表获取。历史结论不等同当前事实。 |
| 财务诊断与比较 | SEC 同口径现金转化、增长、净债务、公司比较；半导体首版使用库存、成本等标准披露，分部/订单/产能等未覆盖项保留缺口。 |
| 历史时点财务 | `asOf` 先限制原始事实的披露日期，再选版本或拆季度；前后累计来源均须当时已公开。没有历史数据时不会退回当期。 |
| 估值情景 | 用户提供 EPS、股数、股权自由现金流和 PE/FCF 收益率假设；分别计算每股情景价及范围。不是自动预测或DCF。 |
| 行情与公司行动 | IBKR 只读 last/bid/ask 和行情权限标记；SEC 申报股数单列，不能作为当日准确总股本。8-K发现材料，结构化分红/拆股由用户提供并保留来源。 |
| 事件与财报 | SEC 已披露事件索引、官方指引/电话会/业绩材料发现与正文阅读；实际值与事前指引/共识比较使用用户提供、带来源及时间的同口径值。没有可靠共识供应商时不编造一致预期。 |
| 宏观 | FRED/ALFRED 单序列；当前公开 CSV 不带完整元数据，历史 vintage 需要 `FRED_API_KEY` 环境变量或本地 `macro.fred.api-key`。历史查询不会降级为今天修订值。 |
| 组合、ETF、筛选 | 用户表格的分币种敞口、集中度、情景损益、日期对齐相关性；ETF单层穿透与重叠；显式股票池逐规则 PASS/FAIL/UNKNOWN。见[组合契约](portfolio-calculations.md)。 |
| 市场历史复盘 | 美股日线波动、回撤、基准收益差及事件窗口；保留实际交易日范围、复权未知和常规收盘对齐限制，不当作总回报、策略收益或因果证据。 |
| 期权 | 用户提供的带时间/来源期权链，最近有效行权价跨式估计范围；显示点差、流动性、覆盖不足。没有期权数据权限时不伪造实时报价，不提供交易能力。 |

## 执行与边界

`GET /api/research-tools` 返回工具的真实 `@Tool` schema、示例及可执行 Skill 清单；`POST /api/research-tools/{name}` 使用参数对象执行单工具；`POST /api/research-tools/skills/{id}` 使用声明输入执行 Skill。接口均要求已登录用户，沿用 Session/CSRF。私有研究读取还逐次核对用户归属；用户 ID 不能放进工具参数。

工具只从 `ResearchToolCatalog` 显式注册的对象中产生。Skill 的唯一清单在[后端 resources/skills](../stocksage-backend/src/main/resources/skills)：`TOOL` 步骤的 `capability` 指定工具名，`arguments` 只支持字面量和 `$input.<字段>`，不能执行表达式或任意代码。`inputs` 是可编辑输入示例，`method` 是解释结果时应遵守的方法。Skill 输出确定性证据与方法说明，不额外调用模型生成报告。

普通对话保持既有确定性取证和无工具 Agent。NEWS 自动选择只含 `CAPABILITY` 步骤的 Skill；新增研究 Skill 从工作台明确执行，不宣称任意自然语言问题已能自动选择全部流程。DEEP 的 `evidence_read` 只能从本轮账本里的 evidenceId 解析已观察来源，经原文能力读取；未知编号或无法准确定位的申报会拒绝。混合来源证据仅展开已标明的首段文档，并显示其余来源数量或未知，不冒充全部读完。

执行共享有界线程池，继承当前认证身份，按单工具/Skill截止时间中断；零可用结果为 FAILED，部分覆盖保留 PARTIAL 和逐步缺口。结果大小受限；工具数值和原文仍由各自契约校验。调度、通知、交易和自动写入知识库不属于这些 Skill。

实现验证与未完成的在线链路统一见[交付记录](../evals/results/tools-complete-20261028/README.md)。
