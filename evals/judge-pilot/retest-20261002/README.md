# 普通回答判官独立重测：2026-10-02

本目录用四份新的官方季度公告构造 20 个普通回答样例，重测同一评测器。每家公司有两个正确回答，以及数值错误、明确子问漏答、无依据确定性各一个变体；组内问题与证据完全相同。

[预注册设计与指标](test-design.json)定义运行条件、目标维度和判定要求；五维标准只引用[现行 ordinary_rubric()](../../ordinary_answer_quality.py)，不在此重复维护。

[冻结样例](cases.jsonl)包含 20 条 VALIDATION 记录、4 个来源组和 100 项标签。两名 AI 作者分别核对官方来源，另一名 AI 复核者独立打开四个官方链接并检查全部标签。所有记录为 AI_CROSS_CHECKED，无未解决争议；具体覆盖、绑定、算术检查和复核理由见[标签复核记录](label-review.json)。

来源说明：[Home Depot / UPS](part-a-sources.md)、[FedEx / NIKE](part-b-sources.md)。合并样例及标签复核记录为本轮冻结参考集；part-a.jsonl、part-b.jsonl 保留作者阶段材料。

这些答案由 AI 编写，标签经 AI 交叉核查，**不是人工金标，也不是业务 Agent 的真实输出**。结果只能说明同一评测器对这组受控常见错误的识别能力，不能证明真实业务端到端质量、广泛跨域能力或发布资格。本集没有预期 NO_DATA 样例，也没有数值维度的 NOT_APPLICABLE 样例，因此不检验这两类行为。

文件与规范化数据的 SHA-256 均保存在[标签复核记录](label-review.json)，后续运行应绑定这份冻结记录。

本轮实际运行、指标及结论见[独立重测结果](RESULTS.md)。
