# Ordinary 评测体系修正与真实校准结果

标准、标签绑定、局部错误归属和统计口径的修复已完成。固定 Max 判官未达到本轮预先冻结的诊断目标，状态为 `JUDGE_NOT_ACCEPTED`；本报告不授予业务进化或发布资格。

## 修复与标准

- 语义判据统一来自 [ordinary_rubric()](../../../../ordinary_answer_quality.py)，本轮[冻结快照](../../rubric.json)包含五个独立维度、状态适用范围、摘录要求和跨维归因。
- 42 题的 210 项标签先按标准完成两个 AI 角色的逐项复核；两处分歧解决后才冻结，见[标签审阅记录](../../label-review.json)。旧 30 题全部作为 DEV；新四个来源组的 12 题作为 VALIDATION。
- runner 与校准器使用同一维度校验函数。单项摘录失败不会污染其余维度，输入绑定或整份响应失败才影响全案。技术有效、已知判断覆盖、条件语义一致与合理弃权分开统计。
- 完整证据直接提供，计算工具按需使用；每轮 JSON 模式，最后一轮不再提供工具。候选提议器读取同一标准、真实 DEV 工具轨迹和预算，保留正确样例；验证标签不进入提议器。

## 固定判官的真实结果

最终版本使用 `qwen3.8-max`，实际响应模型同名；DEV 30 题、VALIDATION 12 题，各重复两次。数据、标准、提示词、runner、模型参数和诊断目标的冻结记录见 [run-plan.json](run-plan.json)。看到验证结果后没有修改本轮标准、标签或提示词。

| 指标 | DEV | 新 VALIDATION |
|---|---:|---:|
| 技术有效维度 | 293/300（97.7%） | 116/120（96.7%） |
| 已知判断覆盖 | 287/292（98.3%） | 116/120（96.7%） |
| 有效已知判断与标签一致 | 265/287（92.3%） | 95/116（81.9%） |
| 全项目标签一致 | 271/300（90.3%） | 95/120（79.2%） |
| 相对参考标签误放 | 11/76（14.5%） | 4/33（12.1%） |
| 相对参考标签误杀 | 1/211（0.5%） | 4/83（4.8%） |
| 材料不足项正确处理 | 6/8（75.0%） | 无此类标签 |
| 完整有效重复的稳定性 | 25/26（96.2%） | 8/9（88.9%） |

每个重复算一个评审尝试，每次包含五项维度。技术失败不计语义正确，语义一致率仅以有效且双方标签已知的维度为分母；误放是参考 FAIL 被判 PASS/N/A，误杀是参考 PASS/N/A 被判 FAIL。公式与各维矩阵见 [DEV 校准](dev-calibration.json)、[VALIDATION 校准](validation-calibration.json)。重复稳定性分别排除了 4/30、3/12 个含无效评审的案例，不能将这些案例当作稳定。

两组均未达到全部预设目标。开发集的反证一致为 43/58，验证集为 9/24，这是本次最明显的语义短板。验证集另有 4 项摘录无效、4 项相对标签误放及 4 项误杀；最终两个 split 的 JSON 解析和网络全局失败均为 0。逐项目标结果与错误计数见 [verification.json](verification.json)。

这些是与 AI 参考标签的一致性，不是人工一致率或生产准确率。独立 DEV 复核确认存在指标名称漏检、虚构披露漏检和把已处理反证当不适用；部分任务覆盖还存在解释边界，见 [DEV 分歧复核](dev-discrepancy-review.json)。

## 验证与证据边界

- 离线评测回归 232 项通过；最后一次输出协议修改后，相关 27 项再次通过，两组计数重叠。fast 基线通过，后端 772 项中 1 项真实接口测试跳过，前端测试/构建和 Python 编译通过。
- [真实协议 smoke](transport-smoke.json)保留 calculate → tool 结果 → JSON 的完整响应，确认供应商支持本次组合；JSON 支持依据见[阿里云官方文档](https://help.aliyun.com/zh/model-studio/qwen-structured-output)。这项检查不等于摘录或语义校准通过。
- [首轮 DEV](../20261001-fixed-judge/dev.json)的技术失败保留原样，其验证集没有运行；输出约束修正后使用新的运行身份。两轮 runtime/guidance 同时变化，不能解释为纯提示词 A/B 效应。
- 历史 17 个数据/运行文件的 SHA256 均未变化，见[原始指纹](historical-artifact-digests.json)。既有业务 HOLDOUT 未读取、未运行；新验证集已用于本轮观察，后续调参需要新的独立验证组。
- 本次修复期间共 147 个评审尝试、221 次 API 调用、495,810 tokens，包含首轮 DEV 与 smoke。最终冻结版本的 84 次评审共 116 次 API 调用、266,715 tokens。金额未配置，保持未知。

下一步是提升固定标准下判官对反证、指标口径和覆盖范围的执行一致性，并在新的独立验证组复验。当前结果不能用于自动批准业务 Agent 的进化候选。
