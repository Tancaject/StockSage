# 判官校准集 v2

评价标准的唯一权威来源是 [ordinary_answer_quality.py](../../ordinary_answer_quality.py) 的 `ordinary_rubric()`；本轮冻结快照见 [rubric.json](rubric.json)。本目录是新数据版本，旧目录中的标签和历史运行产物保留原样，不能与新分数直接混用。

[cases.jsonl](cases.jsonl) 收录 42 个编写样例：旧 30 例重新按冻结的五维标准审阅，全部列入 DEV；另建四家新公司的 12 例作为 VALIDATION。旧验证集已经暴露，保留 `original_split` 仅用于来源追溯，不能继续当独立验证。新验证公司的来源报告与开发集不重叠，没有使用既有业务 HOLDOUT。

- 答案身份为 `AUTHORED_CALIBRATION`，不是 StockSage 真实输出。
- 证据为官方报告事实的中文规范化摘录；英文逐字引文与中文转述不得混称。每行保留 URL、原始章节及证据来源身份。
- 参考标签为 `AI_SOURCE_CHECKED`，逐例绑定 `rubric_sha256`。标签审查状态、不同审核角色和理由见每行 `label_review` 及 [label-review.json](label-review.json)。
- 作者审阅阶段为 `AI_REVIEWED`；第二个 AI 独立检查标签理由并解决分歧后才记录 `AI_CROSS_CHECKED`。未解决分歧记为 `DISPUTED`，不得进入校准比较。
- 两个 AI 一致不等于人工金标、发布批准或真实业务效果验证。完整样例没有实际执行 Trace，不能评价工具运行或证据采集质量。

五维独立应用冻结标准：事实成立、数值口径、反向经营事实、信息边界和任务覆盖。覆盖到所有子问但内容错误仍可在覆盖维度通过；反证已讨论但数值错，不再按未涉及重复扣分；虚构明确未披露的指标，即使用“预计”也不能通过信息边界维度。这里只说明数据如何按标准标注，不另行维护一套评分定义。

缺失来源控制例保留为空证据：依赖来源的四维为 NO_DATA，但完整问题和答案仍允许判断任务覆盖。N/A 仅按冻结标准允许的维度使用，不把已妥善处理的反向经营事实当不适用。

## 分组与隔离

DEV 为旧数据的十个来源组，具体原分割可由 `original_split` 查看。新 VALIDATION 为以下四组，每组三个变体：

| 来源组 | 官方报告定位 |
|---|---|
| jpm-cy2025-q1 | JPMorganChase 1Q25 官方盈利公告，第 2 页集团结果与信用损失 |
| visa-fy2025-q2 | Visa 向 SEC 提交的 FY2025 Q2 盈利公告 |
| ko-cy2025-q1 | Coca-Cola 2025 Q1 公告的收入与北美经营说明 |
| pep-cy2025-q1 | PepsiCo 向 SEC 提交的 2025 Q1 结果及全年指引 |

模型仅获得题目、答案、证据及必要来源信息。不能把预期标签、标签审查、`rationale`、重新标注原因或原分割发给模型。VALIDATION 只在标准、提示词和候选方案固定后运行；不得根据其逐题结果调整同轮候选。若已经这样使用，必须如实标为暴露并换用新独立组。

[label-review.json](label-review.json) 保存本轮标签复核与数据冻结身份；性能报告由运行脚本生成。样本数量和 AI 标签来源决定了它只支持小规模判官诊断，不能将一致率解释为生产语义质量。

本轮真实校准的指标、预设目标和验收结论见[固定判官运行报告](runs/20261001-json-contract/README.md)。
