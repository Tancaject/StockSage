# 普通答案判官校准集

本目录的根层数据及 `runs/20261001` 保留 v1 历史实验。当前校准入口为 [v2](v2/README.md)；以下描述属于旧实验，不代表当前标准或未使用的验证集。

这是评测 Agent 的小规模校准材料。它不评价 RAG 检索质量，也不是业务 Agent 的真实任务成功率数据。

`cases.jsonl` 是本数据集的权威内容：30 个由 AI 编写的答案变体，来自 10 家公司的 10 份公开公告或官方发言，每组 3 个案例。18 个 DEV 案例用于开发；12 个 VALIDATION 案例用于固定候选后的独立验证。公司和来源报告都不跨组、不跨分割。没有读取或复用既有业务 HOLDOUT。

- `answer_origin=AUTHORED_CALIBRATION`：答案是校准用编写样例，不是 StockSage 的实际模型输出。
- `label_origin=AI_SOURCE_CHECKED`：标签由 AI 对照官方来源及独立算术核查建立，未经人工标注；它是开发阶段的参考标签，不能证明人工一致性或发布资格。
- `evidence_origin=AI_NORMALIZED_OFFICIAL_SOURCE`：证据是官方数值表和说明的中文规范化事实摘录，不冒充英文逐字引文。URL 和原网页章节在每行内保留，判官引用的是冻结的可见证据字符串。
- 模型输入仅使用问题、答案、证据和必要的来源元数据；不得传入 `expected_dimensions`、`rationale`、标签身份或能揭示预期结论的案例说明。
- VALIDATION 不进入提示词生成、候选选择或错误示例库。若已看结果并据此修改候选，必须将该轮标为验证集已暴露，重新收集独立验证组。
- 本集以常见事实、算术、口径、遗漏和不确定性为主。它没有真实执行 Trace，因此不能验证工具执行、来源采集或端到端业务成功。

## 标签解释

四个维度分别评判；事实错误不自动使所有维度失败。

| 状态 | 本集中的用法 |
|---|---|
| PASS | 有足够材料，满足该维度要求。 |
| FAIL | 有足够材料识别实质错误，例如原值错配、算术错误、遗漏已知反面证据或把预测当保证。 |
| NOT_APPLICABLE | 此维度确实不涉及：没有需核算的数值主张，或没有与问题和结论相关的反向证据。不要求补无关负面观点。 |
| NO_DATA | 本轮捕获材料不足，无法完成该维度判定。不得用模型记忆或来源链接存在代替捕获证据。 |

`counterevidence` 只判断是否漏掉相关的重要反向信息。已陈述事实可以正确，同时因遗漏另一个重要指标而在该维度失败。GAAP/非GAAP、收入/费用、季度/年度等直接错配归入事实与数值维度；不能仅为增加失败数而将每处错配都标为遗漏。

`unknowns` 检查额外的确定性、因果和推断边界。单纯减法算错不自动成为不确定性错误；把管理层预期变成必然实现则失败。年份或季度名称本身不意味着存在需要数值核算的财务主张。

`msft-fy2025-q4-03` 故意移除捕获证据，其答案内容可能正确。四维标为 NO_DATA，模拟评测材料采集缺失；来源 URL 不能替代缺失上下文。其他证据完整案例中无依据的积极主张仍判 FAIL，不能滥用 NO_DATA 放过。

每个组的完整官方 URL、源标题和章节保留在 JSONL；下表仅标识定位，不另行维护数值。

本次对照官方网页核实事实、单位、期间和口径，并用独立的 `Decimal` 运算核验案例涉及的减法、同比和百分点差。结构检查要求唯一 ID、每组只属于一个分割、四维标签齐全，以及答案身份明确。测试执行记录由项目进度或本轮运行产物保存。

校准报告应分别给出误放、误杀、覆盖率、逐维一致性、重复评测稳定性和成本，保留与参考标签的分歧。样本小且标签由 AI 建立，不能把高一致率解释为判官已获生产验证。
