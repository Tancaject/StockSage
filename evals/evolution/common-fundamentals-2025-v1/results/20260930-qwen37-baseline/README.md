# 2026-09-30 基本面真实基线评测

12 道常见基本面问题全部完成两阶段真实调用。必答金额和计算结果均匹配冻结答案，但最终回答的 12 题都存在需要修正的解释，严重程度不同：包括无来源的业务归因、过度确定的偿债判断，以及科目误述和额外计算错误。

这是 AI 对照官方报表进行的初评，尚无人类独立验收，也没有候选版本对照；不能据此判断自进化带来了提升。

## 数据与执行

- [数据集设计与运行命令](../../README.md)：6 家公司、18 题，覆盖增长与利润率、现金流与资本开支、流动性。来源为 FY2025 官方财务报表，没有加入攻击、极端缺数或罕见业务情形。
- 本轮执行 Microsoft、Walmart、Alphabet、Costco 的 12 题，每题一次；Apple、Amazon 的 6 题留出集未调用。运行前固定答案，答案不进入模型输入。
- 实际模型均为 `qwen3.7-plus`，温度 0.7，最大输出 4096 tokens。调用真实 `FundamentalsAgent → ChatPromptAssembler → Coordinator` 组件；使用冻结证据，不覆盖在线检索、路由、登录、数据库或整站部署。
- 评测进程单阶段上限及 HTTP 读取上限均为 120 秒。生产配置未在本轮修改。构建身份为 `UNATTESTED`，不作为打包发布验收。
- 显式 Maven 运行退出码 0：一个测试方法完成 12 个案例、24 次模型调用，耗时约 18.3 分钟。HTTP 初始化修复另有本地 11 秒延迟响应和脱敏检查通过。

“必答金额/计算匹配”只覆盖冻结答案要求的数值，不代表所有扩写都正确。允许单位换算、规定的四舍五入、正确的额外年度比较，以及明确标为假设的合理推断；对具体公司原因、管理层意图或信用风险作无证据断言才计入相应问题。单一来源题末的 `[E1]` 可以接受，不要求每句话重复引用。

| 案例 | 分析稿 | 最终回答中的主要问题 |
|---|---|---|
| MSFT 增长 | 销售与营销费用误称销管费用 | 增添云/AI 业务占比归因，并延续科目误述 |
| MSFT 现金流 | 无来源的资本开支投向、管理层动机 | 把 AI/云投向和长期押注写成事实 |
| MSFT 流动性 | 低估递延收入履约的现金需求，偿债判断过强 | 声称“长期债务……毫无压力” |
| WMT 增长 | 通过，具体驱动因素保留为推断 | 把潜在驱动改成确定的主要原因 |
| WMT 现金流 | 无来源的具体投资投向 | 进一步断言具体战略和“必经之路” |
| WMT 流动性 | 缺相应数据却断言存货周转与现金流强 | 延续未经证实的经营优势和偿债判断 |
| GOOGL 增长 | 从费用增加推断战略意图 | 确定宣称用短期利润换 AI 技术壁垒 |
| GOOGL 现金流 | 将 PP&E 支出扩大为包含无形资产等 | 增添 AI 转型、营运资金管理质量等归因 |
| GOOGL 流动性 | 通过，保留静态指标与资料缺口的边界 | 声称“毫无压力”，并预测无依据的新增利息金额 |
| COST 增长 | SG&A 占收入比例实际上升，却写成下降 | 未沿用该方向错误，但新增“会员费是最核心引擎”断言 |
| COST 现金流 | 无来源的投资投向、配置纪律判断；额外 CAGR 有误 | 延续投向和配置判断，以及额外 CAGR 错误 |
| COST 流动性 | 仅凭静态表过度判断信用风险 | 声称“根本不存在长期债务违约风险” |

这份表区分了两种后续工作：分析稿自身的科目、计算和证据边界，以及最终回答将假设改写为事实的行为。仅修改分析师方法是否能同时改善最终回答，需要成对评测验证。

12 次分析师调用全部超过原配置的 30 秒等待上限。此次 120 秒运行证明了较宽上限下的完成情况，不能证明原上限足够；普通应用最终流式回答的超时机制也不在本轮验收范围内。

本轮提供商用量合计 **135,197 tokens**（输入 72,686，输出 62,511）。流式重复累计快照每次调用只取最后一份，没有重复累加。没有配置计价或核对账单；此前失败调用可能有未知用量，未当作零成本。
